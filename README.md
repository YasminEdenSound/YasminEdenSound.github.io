# YasminEdenSound.github.io

A one-page site for an independent mixing, mastering and recording engineer.
Static — no build step, no dependencies, no server.

## Editing it

Open **`/editor.html`** and change anything on the page from a form, with the
real site previewing beside you. It publishes straight to this repository.

Start here: **[EDITING.md](EDITING.md)**.

## The files

| File | What it is |
|---|---|
| `index.html` | The whole site — markup, styles and the scroll-driven instrument |
| `content.js` | Every editable word, photo path and number, as JSON |
| `editor.html` | The form over `content.js`; writes to GitHub via the Contents API |
| `assets/` | Photos and audio — see [assets/README.md](assets/README.md) |
| `robots.txt` | Kept in step with the launch switch in the editor |
