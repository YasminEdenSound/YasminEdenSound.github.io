Publishing to GitHub

Publishing writes your changes straight into the repository that serves the site. It needs a token — a long password GitHub gives you, which lets this page save files on your behalf. You make it once.

The token is kept in this browser only — it is never sent anywhere except to GitHub. Anyone who can use this browser profile can publish with it, so don't save it on a shared or public computer. Forget token removes it.
How to make the token (2 minutes)
  1. Open github.com/settings/personal-access-tokens/new while signed in to GitHub.
  2. Token name: anything, e.g. site editor.
  3. Expiration: pick a long one. When it expires, publishing stops working and you make a new one the same way.
  4. Repository access: choose Only select repositories, then pick the repository named above.
  5. Permissions → Repository permissions → Contents: set to Read and write. Leave everything else alone.
  6. Press Generate token, copy the github_pat_… string, paste it into the Token box here, and press Save.

Passphrase for this page

The passphrase only hides the editor from passers-by — it is not real security, and it is not what protects the site. The token is. Change it here if you like.

Changing it saves a new editor.html to the repository, so it needs the token too.

Download the content file and the photos, then upload them to the repository yourself (or send them on). Everything else in the editor works the same.
